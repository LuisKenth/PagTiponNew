PAGTIPON - PROVINCIAL MUNICIPALITIES PAGE

Installation:
1. Open:
   app/dashboard/provincial/municipalities/

2. Delete or back up the current files inside that folder.

3. Copy all files and folders from this package into:
   app/dashboard/provincial/municipalities/

Included structure:
- page.tsx
- components/
- constants/
- hooks/
- types/
- utils/

The package preserves:
- Supabase profiles query
- Municipal admin approval
- Municipal admin rejection
- Approved administrators list
- Pending administrators list

The package adds:
- All 18 municipalities of Antique
- Municipality coverage overview
- Assigned, pending, and unassigned status
- Responsive cards and tables
- Cleaner reusable components
